# Telegram-бот «Сон ребёнка»

Python 3.11+, aiogram 3, async SQLAlchemy, SQLite/PostgreSQL и APScheduler.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env  # Linux/macOS: cp .env.example .env
# укажите BOT_TOKEN в .env
python bot.py
```

Таблицы создаются автоматически. Для production рекомендуется запускать один экземпляр бота: задания APScheduler хранятся в памяти и восстанавливаются из БД при старте. Локально можно использовать SQLite, но на Render нужна PostgreSQL, иначе данные исчезнут после перезапуска.

## Постоянная база на Render

1. В Render Dashboard выберите **New → Postgres** и создайте базу в том же регионе, что и бот.
2. Откройте созданную базу и скопируйте **Internal Database URL**.
3. В сервисе бота откройте **Environment → Add Environment Variable**.
4. Создайте переменную `DATABASE_URL` и вставьте URL целиком без кавычек.
5. Выполните **Manual Deploy → Deploy latest commit**.

URL вида `postgres://...` или `postgresql://...` автоматически преобразуется для async-драйвера. Пароль базы нельзя добавлять в GitHub или `.env.example`.

Команды: `/start`, `/join CODE`, `/status`, `/reset`, `/cancel`.

## Семейный режим и приватность

- При подключении пользователь выбирает подпись: «Мама», «Папа», «Бабушка», «Няня» или своё имя.
- Первый `/start` предлагает создать новую семью или подключиться к существующей по коду.
- `/join CODE` работает из любого шага онбординга и не принимается за имя ребёнка.
- Администратор может выполнить полный сброс семьи, а участник — безопасно выйти из неё. Оба действия требуют подтверждения.
- База атомарно защищена от двух одновременно запущенных таймеров сна.
- У каждой записи хранится автор; системные уведомления рассылаются всей семье.
- В настройках администратор может включить тихий режим 22:00–07:00: напоминания в этот период пропускаются, ответы доставляются без звука.
- В настройках доступен UTF-8 CSV за 7 или 30 дней. Он открывается в Excel и формируется в памяти без временных файлов.

Часовой пояс задаётся через `BOT_TIMEZONE` при создании профиля. Даты хранятся в UTC.
